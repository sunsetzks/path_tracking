## 使用方法

```bash

python run_mpc_test.py

python simple_mpc_example.py
```

### 自定义使用
```python
from mpc_core import solve_linear_mpc
import numpy as np

# 创建参考轨迹
reference_trajectory = np.zeros((4, 6))  # 4 states, 6 time steps
reference_steering = np.zeros((1, 6))

# 设置初始状态
initial_state = [0.0, 0.0, 0.0, 0.0]

# 创建线性化轨迹
linearization_trajectory = reference_trajectory.copy()

# 求解 MPC
result = solve_linear_mpc(
    reference_trajectory,
    linearization_trajectory,
    initial_state,
    reference_steering
)
```

## 技术细节

### MPC 参数
- **状态维度**: 4 (x, y, velocity, yaw)
- **控制维度**: 2 (acceleration, steering_angle)
- **预测时域**: 5 步
- **时间步长**: 0.2 秒

### 约束条件
- **最大速度**: 15.28 m/s (55 km/h)
- **最小速度**: -5.56 m/s (-20 km/h)
- **最大加速度**: ±1.0 m/s²
- **最大转向角**: ±45°
- **最大转向速率**: ±30°/s

### 成本函数
- **状态跟踪成本**: 位置和速度偏差
- **控制成本**: 加速度和转向角
- **控制变化成本**: 平滑控制输入
- **终端成本**: 最终状态偏差
